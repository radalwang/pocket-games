# 飞行棋：联机怎么接

开局设置里点「联机对战」进大厅（`js/lobby.js`，快速匹配或房间码），凑齐人后服务器开局。服务器说了算：骰子由它掷、动作由它用同一份 `rules.js` 检查，电脑、超时（每步 15 秒）和掉线的人都由它替着走。消息格式和服务器怎么跑见 `server/PROTOCOL.md`，这里只写客户端这边。

## 分层

```
界面 index.js ──roll() / move(飞机)──▶ 对局 match.js ──server(意图)──▶ 连接 js/online.js ──▶ 服务器
      ▲                                   │   ▲                                    │
      └──── 事件 events（放动画） ◀────────┘   └──── accept(seq, 动作) ◀── 排队 ◀────┘（act 广播）
                                          │
                                  规则 rules.js（纯计算）
```

- **rules.js**：给开局设置、局面和动作，算出新局面和事件。不碰页面、不用随机数，服务器直接拿它当裁判。
- **动作**：`{ type: 'roll', seat, value }`、`{ type: 'move', seat, plane }`，`seat` 是 `config.players` 的下标。
- **座位 `seats`** 是每台设备自己的看法：联机时自己是 `local`，其余（包括服务器替它走的电脑）都是 `remote`。
- **`new Match({ config, seats, log, server })`**：传了 `server(intent)` 就是联机模式。`roll()` / `move(飞机)` 不自己走，只把意图 `{ type: 'roll' }` / `{ type: 'move', plane }` 交给它发出去；回音到之前再点不会重复发（`pending`）。服务器广播回来的第 `seq` 步用 `accept(seq, action)` 执行：接得上就执行，重复的忽略，跳号或执行不了抛错（这时重新 `resume` 要整局）。意图被拒（`bad-action`）时调 `reject()` 可以再点。不传 `server` 就和单机完全一样。

## 界面（index.js）

- **节奏**：收到的 `act` 先排队，前一步动画放完再执行下一步；队排空了发 `{ t: 'idle', seq: log.length }`，服务器才让下一个人出手、开始计时。拿到 `start`（开局、回来、重连）时直接按 `log` 重放出局面，不放动画，马上回 `idle`。
- **名字、计时、掉线**：牌子上写昵称（你写「你」，太长省略），倒计时的人牌子底下有根细条在缩短，轮到你时状态栏写「还剩 N 秒」；掉线的人牌子变淡、写「掉线代打」，并弹一句提示。超时被替你走了也会提示。
- **存档**：联机时只存 `{ online: { room, token }, setup, counted }`，继续条写「联机对战中 · 你是红方」。打开 App 时凭它连上去 `resume`；服务器说 `no-game` 就提示「这局联机已经结束」回到开局设置。下完了、退出了就存成 `{ setup, ended: true }`（已结束），再打开不再连。`counted` 跟着存档走，回来时不会重复记赢。
- **前后台**：收起游戏页、看玩法介绍时不断开（动画直接跳到结尾，别人不用等你）；真的切到后台就断开，服务器马上让电脑代打，回到前台再连上回来。在前台意外断开就按 1、2、4、8 秒重连，还不行就给「重试 / 退出」。
- **退出和结束**：联机时点「新一局」会问「退出联机对局？你的座位会交给电脑」，确定后发 `leave`。下完显示赢家的昵称，「再来一局」回大厅，「返回」回开局设置。

## 设备之间直连（没在用）

`match.js` 里还留着不经过服务器、设备之间直接联机的一套：`link`（`send` / `onMessage`）和 `action`、`sync`、`check` 三种消息，用两个 `Match` 通过回环 link 互相连上验证过。现在的联机走服务器，用不到它们。

## 已经验证过的

- 用 `server/hub.js` 加假时钟、假网络（随机延迟、偶尔重复收到同一条），两三个客户端用联机模式的 `Match` 下了 40 局（2–4 人，2/4 架飞机，有电脑、有超时、中途有人断线再回来）：每个客户端的 log 都和服务器一样，局面和 `rules.replay` 一样，没有乱序执行过。
- 连真的服务器（`ws://localhost:8787/online`）下了 3 局，包括断线重连、结束后的 `resume` 和 `no-game`。
- 用一个最小的假 DOM 跑 index.js：大厅开房间到开局、整局下完（暂停、切后台、断网重连、对手掉线）、卸载后凭存档回来、`no-game`、退出、服务器连不上时的重试 / 退出、快速匹配只有自己时「和电脑玩」，以及单机一局打到底和读档。
