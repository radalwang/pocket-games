# 大富翁：联机是怎么接的

开局设置里点「联机对战」进大厅（`js/lobby.js`：快速匹配或房间码），凑齐人后由服务器（`server/`）开局。消息格式、限时、掉线代打以 `server/PROTOCOL.md` 为准，这里只记大富翁这一头。

## 分层

```
界面 index.js ──submit(动作)──▶ 牌桌 table.js ──send──▶ transport
                                      ▲                    │
     ◀── 事件(events) + 新局面 ────────┴──receive(动作)◀────┘
                                      │
                               规则 engine.js（纯计算）
```

- **engine.js**：给局面和动作，算出新局面和事件。不碰页面、不读时间，服务器直接拿它当裁判。动作是 `{ type, by }`（`roll` / `buy` / `upgrade` / `pass` / `resign`），能不能做只看 `canAct`。`roll` 带了 `dice` 就用这个点数。
- **table.js**：动作都经 `submit` 交给 transport，再由 transport 送回 `receive` 执行，`rev` 对不上的丢掉。`LocalTransport` 原样马上送回（本机轮流玩、和电脑玩）；`OnlineTransport` 只把 `{ t: 'act', action: { type } }` 发给服务器。
- **座位由谁操作**（`controller`）：`local` 本机真人给按钮，`ai` 本机替电脑出手，`remote` 等别处的动作。

## 联机时这台手机做什么（index.js）

- **牌桌**：按服务器的 `start` 搭 `new Table({ config, seed, log, transport, seats: [我的座位], hostsAI: false })`，电脑和别人都是 `remote`（电脑由服务器出手）。
- **只执行广播**：服务器掷骰子、排先后，把 `{ type, by, rev, dice? }` 广播给所有人（包括自己）。发出动作到收到广播之间按钮变灰，免得点两下。认输随时都能发。
- **节奏**：广播来的动作先排队，上一个的动画播完再执行下一个；队列空了发 `{ t: 'idle', seq: log 长度 }`。搭好牌桌后也马上发一次。`seq` 跳号或者执行不了，就在同一条连接上再发 `resume`，用完整局面重搭。
- **限时、掉线**：收到 `turn` 开始倒计时：自己的回合按钮下面写「还剩 N 秒」，别人的回合卡片底下一条线慢慢变短。`presence` 标出掉线的人：卡片变淡，写「掉线 · 电脑代打」（卡片太窄时写「掉线代打」）。
- **存档**：联机时只存 `{ setup, online: { room, token }, counted }`，摘要是「联机对战中 · 第 3/20 轮」。打开游戏看到它就连服务器发 `resume`，用回来的 `start` 把局面直接算到现在（不播动画）。服务器回 `no-game`，或者连了 5 次（隔 1、2、4、8 秒）都连不上：提示「这局联机已经结束」，回开局设置。打完的联机局存成已结束，不再回去。
- **后台**：收起游戏页、看玩法介绍只是 pause（动画快进，照样回 idle），连接不断。真切到后台（`visibilitychange`）就主动断开，服务器马上让电脑代打；回到前台重连再 `resume`。在前台意外断开：提示「连接断了，正在重连…」，按 1、2、4、8 秒重试，还不行给「重试 / 退出」。
- **退出、结束**：「新一局」先问「退出联机对局？你的座位会交给电脑」，确定后发 `leave`。打完后「再来一局」回大厅，「返回」回开局设置。
- **成绩**：自己的座位赢了就记一次 `wins`，`counted` 跟着存档走，重连、重开 App 都只记一次。本机对局照旧：本机玩家赢、而且对手里有电脑才记。

## 还没做

- **抽卡防作弊**：骰子已经由服务器掷，但种子仍在 `start` 里发给客户端，机会、命运的牌堆顺序能提前算出来。要防的话，服务器得在动作里带上抽到哪张（引擎还不支持）。
- **指纹**：`table.hash()` / `engine.hashState()` 现在没用上，靠 `seq` 连续、`rev` 对得上来发现算岔。
